# Trilha do Edson

Jogo 3D de mountain bike para celular, feito para o Edson ([@edsonalexandre_mtb](https://www.instagram.com/edsonalexandre_mtb/)).

**Jogar:** https://scoffyt.github.io/edsonmtb/

- Jogue com o celular deitado. No Android, o jogo entra em tela cheia e trava na horizontal no primeiro toque.
- Dica: no navegador, use "Adicionar à tela inicial" para abrir como app.
- Toque para pular, segure para pular mais alto, toque no ar para dar manobras.

Tudo fica em um único arquivo (`index.html`): modelos 3D, sprites e as vozes do Edson.
